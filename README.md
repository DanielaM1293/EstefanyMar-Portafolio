The site is a visual journey inspired by cinematic and magical worlds, with one section per scene:

- 🪐 **Space:** welcome
- 🌌 **Sky:** about me
- 🌊 **Sea:** personal projects
- 🌿 **Earth:** skills
- ❄️ **Ice Court:** contact

Built with **React, Vite, and Tailwind CSS**, with custom animations and a responsive layout.

### Run it locally

```bash
git clone https://github.com/DanielaM1293/EstefanyMar-Portafolio.git
cd EstefanyMar-Portafolio
npm install
npm run dev
```

Build for production with `npm run build`.
